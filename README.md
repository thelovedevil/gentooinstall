# Gentoo Installer

This project is a curses-based installer for Gentoo Linux. It provides a menu-driven interface to guide the user through the Gentoo installation process.

## Features

*   Menu-driven interface using the `curses` library.
*   Automated partitioning and formatting of disks.
*   Automated download and verification of Gentoo stage3 tarballs.
*   Chroot environment setup.
*   Kernel compilation and installation.

## Installation

To use this installer, you will need a bootable Linux environment with Python 3 and an internet connection.

1.  Clone this repository:
    ```
    git clone https://github.com/your-username/gentoo-installer.git
    ```
2.  Navigate to the project directory:
    ```
    cd gentoo-installer
    ```
3.  Run the installer:
    ```
    gentooinstaller.sh
    ```

## Usage

The installer will guide you through the Gentoo installation process. Follow the on-screen instructions to complete the installation.
